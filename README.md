# FN Master

Актуальная версия: **1.0.5**

В этом репозитории публикуются только готовые бинарные релизы FN Master.
Исходный код приложения в репозитории не распространяется.

## Новая установка

1. Откройте релиз **v1.0.5**.
2. Скачайте **FN_Master_1.0.5_windows.zip**.
3. Распакуйте архив в отдельную постоянную папку, например:
   C:\FN-Master
4. Запустите:
   pp\FN Master.exe

Устанавливать Python не требуется. Кассовое оборудование для первого
открытия интерфейса не требуется.

## Обновление старых версий

Версии 1.0.x с прежним механизмом обновлений получат технический
переходный пакет. После подтверждения обновления программа установит
скомпилированную версию, перезапустится и удалит прежние файлы Python,
байткод, старый runtime и резервные копии исходников.

Журналы работы и локально сохранённые данные инженера не удаляются.

## Примечание

Два небольших файла pp_fn_master.py и pp_updater.py в релизе нужны
исключительно для совместимости со старым загрузчиком обновлений.
Они не содержат кода интерфейса, протокола ККТ или рабочей логики
FN Master. Новым пользователям скачивать их не требуется.
