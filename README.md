# FN Master

## Автоматическая установка

1. Запустите **FN_Master_Setup.exe**.
2. Нажмите **«Установить»**.
3. Если драйвер Viki VCP отсутствует, завершите открывшийся мастер драйвера.
4. Дождитесь завершения установки и закройте установщик.
5. Запустите FN Master через созданный ярлык.

Установщик сам скачивает актуальную версию и проверяет её целостность.
Драйвер Viki VCP встроен в установщик.
Python и ручная распаковка ZIP не требуются.

FN Master после установки автоматически не запускается.
Журналы и настройки инженера сохраняются.

Исходный код приложения в репозитории не распространяется.
